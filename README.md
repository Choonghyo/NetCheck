
# Net:Check(네트워크장비 스마트 점검 서비스)

### 1.프로젝트 소개
 목적: 네트워크 장비 점검 절차를 간편하고 체계적으로 관리하기 위한 서비스
 사용자: 통신 기술직 신입사원 및 현장 엔지니어
 개발기술:  HTML5, CSS3, JavaScript
 주요 기능: 장비 정보 입력, 점검 조건 설정, 장비 상태 자동 진단
 화면구성: 다크 모드, 기능별 탭, PC·모바일 반응형 디자인

### 2. 중간고사용 신규기능
기존 단계별 입력, 확인 흐름에 "장비 상태 자동 진단"기능을 추가함.
사용자가 전원, 링크,알람 상태를 선택하고 JavaScript조건문을 사용해
장비상태를 판정, 결과에 따른 권장 점검 사항을 표시함.

### 3. 사용자 행동 및 판정 조건
사용자행동: 장비 정보 입력 → 점검 조건 설정 → 정보 확인 → 상태 선택 → 자동 진단 → 완료
정상:  전원 정상 + 링크 UP + 알람 없음
주의: 전원 정상 + 링크 UP + Minor 알람
점검 필요: 전원 이상, 링크 DOWN, Critical 알람 중 하나 이상 발생
결과안내: 판정 결과에 따른 메시지와 권장 점검 사항 표시

### 4. 성공 및 예외 처리
성공: 필수 항목을 모두 입력하면 장비 상태를 분석하고 결과를 표시합니다.
입력오류: 장비 정보나 진단 항목을 입력하지 않으면 오류 메시지를 표시하고 입력을 요청합니다.
취소: 점검 시작 안내창에서 취소하면 점검 시작을 중단합니다.
수정: 이전 단계로 이동해 입력값을 수정할 수 있습니다.
재진단: 진단 항목을 변경하면 기존 분석 결과를 숨기고 다시 분석할 수 있습니다.
다시시작: 새로운 점검을 선택하면 장비 정보와 진단 상태를 초기화합니다.

### 5. 테스트 기록
HTML·CSS·JS 연결 : 화면 및 기능 정상 실행 
PC·모바일 반응형 : 화면 겹침 없이 표시 
정상 상태 입력: 정상 판정 및 권장 조치 표시
Minor 알람 선택: 주의 판정 및 권장 조치 표시
전원 이상 선택: 점검 필요 판정 
진단 항목 미선택: 오류 메시지 표시 
이전 단계 이동: 입력값 유지 
새로운 점검 시작: 점검 정보 초기화

본 사이트는 실제 네트워크 장비에 연결하지 않는 학습용 개인 웹 프로토타입. 사용자의 점검 입력값에 따라 서로 다른 분석 결과와 권장 조치를 제공하도록 구현함.
