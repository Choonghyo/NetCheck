### 10주차 추가 및 개선 기능

1. 내비게이션(Navigation) - 상단 메뉴 이동 및 현재 메뉴 강조
2. 반응형 메뉴(Responsive) - 모바일 메뉴 열기·닫기
3. 입력값 검사(Validation) - 담당자 이름 2자 이상 입력
4. 글자 수 표시(Character Count) - 담당자 이름 실시간 글자 수 확인
5. 단계별 진행(Step) - 5단계 점검 진행 상태 표시
6. 데이터 저장(Local Storage) - 점검 결과 저장 및 유지
7. 점검 기록 조회(History) - 저장된 점검 내역 확인
8. 필터(Filter) - 전체·정상·주의·점검 필요 분류
9. 기록 개수 표시(Count) - 필터별 점검 기록 건수 확인
10. 상세 보기(Dialog) - 장비별 점검 결과 팝업 확인
11. 기록 관리(Record Management) - 점검 기록 취소 및 복원
12. 접근성(Accessibility) - aria-current, aria-pressed 적용

- 점검 기록 → `#archive`

### 기능 확인 순서

1. 상단 메뉴를 클릭하여 해당 영역으로 이동합니다.
2. 장비 점검 메뉴에서 담당자 이름을 입력하고 안내 사항에 동의합니다.
3. 장비 정보를 입력하고 단계별 점검을 진행합니다.
4. 전원·링크·알람 상태를 선택하여 점검 결과를 확인합니다.
5. 점검 결과를 저장하고 점검 기록 메뉴로 이동합니다.
6. 전체·정상·주의·점검 필요 필터를 선택하여 기록을 조회합니다.
7. 상세 보기와 기록 취소·복원 기능을 확인합니다.
8. 모바일 화면에서 메뉴 열기·닫기와 목적지 이동을 확인합니다.
