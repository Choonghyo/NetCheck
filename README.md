11주차 

1. 추가 및 변경

- 본문 바로가기: Tab 키로 본문 바로가기 표시 및 이동
- 메뉴 접근성: 현재 메뉴 강조, aria-current 적용, 브라우저 제목 변경
- 이미지 접근성: 대표 이미지 대체 텍스트 개선
- 키보드 접근성: 초점 표시 및 키보드 조작 개선
- 모바일 메뉴: Esc 키로 메뉴 닫기 및 초점 복귀
- 입력 오류 안내: 필수 항목 미입력 시 오류 메시지 및 초점 이동
- 점검 기록 필터: 선택 상태 표시, 결과 건수 안내, 전체 보기 기능
- 기록 관리: 취소·복원 후 초점 유지 및 상세 팝업 접근성 개선
- 캐시 관리: CSS·JavaScript 버전 적용

2. 기존 기능 유지

장비 정보 입력, 단계별 점검, 자동 상태 진단, 결과 저장·조회, 기록 취소·복원, 다크 모드 및 모바일 반응형 기능 유지

3. 기능 확인 방법

- Tab -> 본문 바로가기 및 초점 표시 확인
- 메뉴 클릭 -> 현재 메뉴 강조 및 브라우저 제목 확인
- 모바일 화면 -> 메뉴 열기 후 Esc로 닫기
- 필수 항목 미입력 -> 오류 메시지 확인
- 점검 기록 -> 상태별 필터 및 결과 건수 확인
- 기록 취소,복원 -> 초점 유지 확인
